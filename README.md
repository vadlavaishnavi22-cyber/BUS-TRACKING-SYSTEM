# Bus Tracking System

## Description

The Bus Tracking System is a Python-based project that simulates real-time
tracking of buses using GPS coordinates. It displays bus locations, routes,
speed, and status to help demonstrate how a real-world bus tracking system works.

## Features

- Real-time bus location simulation
- Multiple bus tracking
- GPS coordinate updates
- Bus speed and status monitoring
- Estimated arrival time
- Automated test cases
- Simulation output

## Technologies Used

- Python 3
- Object-Oriented Programming
- CSV
- Unit Testing
- GPS coordinate simulation
